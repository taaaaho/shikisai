# shikisai

iOSアプリ「色彩検定3級対策(非公式)」の公開情報を管理するリポジトリです。

- Home: https://taaaaho.github.io/shikisai/
- 利用規約: https://taaaaho.github.io/shikisai/terms.html
- プライバシーポリシー: https://taaaaho.github.io/shikisai/privacy.html

本アプリは個人開発の非公式アプリであり、一般社団法人色彩検定協会(AFT)とは
提携・協力・監修関係はありません。

ソースコードは非公開リポジトリ（`shikisai-code`）で管理しています。
