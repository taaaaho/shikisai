色彩検定3級対策(非公式)

色彩検定®3級の合格に向けた学習を目的とした、非公式の学習アプリです。 色相環・トーン図・コーディネートやインテリアの図などを見て答える問題を含む全8章・459問のクイズ(選択肢ごとの解説付き)、 本番と同じ60分・100問の模擬試験3回分、PCCSの色相環・トーン図を指で確かめられる配色学習、慣用色名を色見本と一緒に覚えられる暗記カードを、 買い切り・広告なし・オフラインで利用できます。

本アプリは個人開発の非公式アプリであり、一般社団法人色彩検定協会(AFT)とは提携・協力・監修関係はありません。収録している問題・解説・配色データはすべて独自に作成したオリジナルコンテンツで、公式教材・過去問の転載は行っていません。実際の試験の出題内容・合否を保証するものではありません。「色彩検定」は一般社団法人色彩検定協会の登録商標です。

よくあるご質問

  • 購入した「全機能解除」が反映されない
    ホーム画面右上の歯車(設定)にある「購入を復元」をお試しください。改善しない場合は上記メールアドレスまでご連絡ください。
  • 無料で使える範囲を知りたい
    「光と色」の章のクイズ・暗記カードと、配色学習の色相環・トーン図は無料でご利用いただけます。
  • 画面の色が印刷物のカラーカードと違って見える
    アプリ内の色は、PCCSの色記号に対応するマンセル値から算出した近似色です。端末の表示設定や画面の特性により、印刷物とは見え方が異なる場合があります。
  • 問題内容に誤りを見つけた
    該当する章・問題文を添えて上記メールアドレスまでご連絡ください。確認のうえ修正いたします。
